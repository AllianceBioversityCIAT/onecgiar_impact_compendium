----------------------------------------------------------------------

ROLE: Sr. Frontend Developer (awslabsfrontend-mcp-server)
GOAL: Make the /dashboard search bar robust and predictable.

Deliverables
1) Create src/hooks/useDebouncedValue.ts
   - API: useDebouncedValue<T>(value, delay=300)
2) Update src/pages/Dashboard.tsx
   - Manage { q, page, pageSize, sort, category } in state + URL.
   - Debounce onChange (300ms), but pressing Enter triggers immediate fetch.
   - ESC and clear (×) reset q, URL, results, and page=1.
   - Call a single fetchStudies({ q, page, pageSize, sort, category }).
3) Input polish
   - Placeholder color var(--ic-color-neutral); focus outline var(--ic-color-mustard).
   - Add inline clear button (×) and keyboard handler (Esc).

API contract (client-side)
GET /studies?q=&page=&pageSize=&sort=&category=  -> { items: Study[], total: number }
If backend absent, provide mock in src/mocks/studies.ts enabled by VITE_USE_MOCKS.

Acceptance Criteria
- ≤1 network call / 300ms while typing.
- Hitting Enter bypasses debounce and fetches immediately.
- Clearing search resets table + URL (?q removed) and sets page=1.
- Refresh/back preserves q state via URL.

Tests
- src/pages/__tests__/Dashboard.search.test.tsx (debounce, Enter, clear, URL sync)

ROLE: Sr. Frontend Developer (awslabsfrontend-mcp-server)
GOAL: Implement column sorting powered by the server and coordinated with search + pagination.

Scope
- Sortable columns: Year (numeric), Category (string), Title (string, optional).
- Sort state format: sort=<field>:<dir>  (dir = asc|desc)

Deliverables
1) Table header sorting UI
   - In src/components/ui/Table.tsx add props:
     sort?: { field: string; dir: 'asc'|'desc' }

   - Show ▲▼ icon next to active column; inactive columns show faded icon on hover.
   - Keyboard support: header button toggles asc/desc with Enter/Space; aria-sort set accordingly.
2) Dashboard integration
   - Persist sort in useSearchParams (?sort=year:desc).
   - When sort changes, fetchStudies({ q, page:1, pageSize, sort, category }).

3) API contract
   - Server interprets sort; client passes raw string.
   - With mocks enabled, implement client-side sort for parity.

Acceptance Criteria
- Clicking Year or Category header toggles asc/desc; icon state reflects sort.
- URL includes ?sort=; refresh/back restores sort.
- Sorting resets to page=1 and composes with q and pageSize.
- A11y: aria-sort on active column, headers are focusable buttons.
