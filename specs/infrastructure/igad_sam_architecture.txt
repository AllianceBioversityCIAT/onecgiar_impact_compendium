COST TAGGING STRATEGY
====================

All resources tagged with:
- Project: igad
- Environment: testing|production
- Component: frontend|backend|database|auth
- CostCenter: research-platform
- Owner: cgiar-alliance
- CreatedBy: sam-deployment

DEPLOYMENT COMMANDS
==================

Build:    sam build --profile IBD-DEV
Testing:  sam deploy --config-env testing --profile IBD-DEV
Prod:     sam deploy --config-env production --profile IBD-DEV
Delete:   sam delete --stack-name igad-{env} --profile IBD-DEV
